# Точка роста АйТи — сайт

Одностраничный сайт по презентации «Реактивируем и возвращаем ваших клиентов» —
система на базе искусственного интеллекта для стоматологий.

## Что внутри

- **Модуль 1. Возвращаем пациентов из картотеки** — интерактивное демо: ИИ «сканирует»
  картотеку, находит пациентов с незаконченным лечением и готовит персональное сообщение.
- **Модуль 2. Умный помощник 24/7** — демо-чат с тремя сценариями (запись на приём,
  острая боль, вопрос о цене) + калькулятор потерь от неотвеченных звонков.
- **Модуль 3. Анализ звонков** — демо-дашборд: список звонков с разбором «где потеряли /
  как надо» и диаграмма причин срыва записи.

Плюс секции: проблема, три зоны потерь, «как всё работает вместе», безопасность, контакты.

## Демо-приложение «ИИ-куратор» (app.html)

`app.html` — интерактивный дизайн-прототип: ИИ выполняет работу куратора,
администратору остаётся позвонить по готовому сценарию.

Экраны:

1. **Мой день** — задачи на обзвон для администратора (приоритет рассчитан ИИ),
   перезвоны по времени и обработанные пациенты со статусами.
2. **Анализ картотеки** — синхронизация с МИС по API, автоанализ после каждой
   синхронизации + ручной анализ за период; обработанные пациенты исключаются
   из повторного анализа.
3. **Карточка пациента** (на весь экран) — незаконченное лечение, история
   визитов, инсайт ИИ (акции / рассрочка / забота / вечер / семья),
   персональное сообщение и боковая панель «Сценарий звонка» — скрипт по
   5 этапам воронки с отработкой возражений. Итог контакта: записался /
   перезвонить / не дозвонились / отказ / неверный номер + комментарий.
4. **Дашборд руководителя** — возвращённая выручка, конверсия обзвона,
   причины отказов, сравнение администраторов и экономика
   «ИИ-куратор вместо куратора в штате».
5. **Интеграция с МИС** — статус подключения, объёмы данных, журнал
   синхронизаций.

Видео-демо: `demo/demo-ii-kurator.mp4` (записано с прототипа, 1:10).

## Технологии

Чистые HTML + CSS + JavaScript, без сборки и внешних зависимостей.
Сайт полностью автономный — работает офлайн.

## Как посмотреть

Просто откройте `index.html` в браузере, либо запустите локальный сервер:

```bash
python3 -m http.server 8000
# и откройте http://localhost:8000
```

## Структура

```
index.html      — вся разметка (одна страница)
css/style.css   — стили
js/main.js      — логика трёх демо, калькулятора и анимаций
assets/         — логотипы и фавиконка
```
