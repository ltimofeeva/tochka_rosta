# Точка роста АйТи — сайт

Одностраничный сайт по презентации «Реактивируем и возвращаем ваших клиентов» —
система на базе искусственного интеллекта для стоматологий.

## Что внутри

- **Модуль 1. Возвращаем пациентов из картотеки** — интерактивное демо: ИИ «сканирует»
  картотеку, находит пациентов с незаконченным лечением и готовит персональное сообщение.
- **Модуль 2. Умный помощник 24/7** — демо-чат с тремя сценариями (запись на приём,
  острая боль, вопрос о цене) + калькулятор потерь от неотвеченных звонков.
- **Модуль 3. Анализ звонков** — демо-дашборд: список звонков с разбором «где потеряли /
  как надо» и диаграмма причин срыва записи.

Плюс секции: проблема, три зоны потерь, «как всё работает вместе», безопасность, контакты.

## Технологии

Чистые HTML + CSS + JavaScript, без сборки и внешних зависимостей.
Сайт полностью автономный — работает офлайн.

## Как посмотреть

Просто откройте `index.html` в браузере, либо запустите локальный сервер:

```bash
python3 -m http.server 8000
# и откройте http://localhost:8000
```

## Структура

```
index.html      — вся разметка (одна страница)
css/style.css   — стили
js/main.js      — логика трёх демо, калькулятора и анимаций
assets/         — логотипы и фавиконка
```
